# UI Reference Index

Este directorio no duplica las imágenes de diseño.

Las referencias canónicas están versionadas en:

`apps/frontend/LockerBoard-marca/ReferenciasPaginas/`

`manifest.json` funciona como índice machine-readable para agentes y automatización visual.

## Reglas

- Usar siempre la versión marcada como vigente en el README de cada ruta.
- No regenerar una referencia disponible solo para mejorarla.
- Las versiones históricas permanecen como contexto, no como source of truth.
- `ignoredRegions` solo cubre assets deliberadamente fuera de alcance, nunca errores de layout.
- La imagen manda sobre composición/estilo; Architecture/Roadmap mandan sobre comportamiento.
- Un CTA o feature dibujado pero marcado como futuro no debe implementarse automáticamente.
- Landing permanece fuera del workstream actual.
- Variantes móviles pueden derivarse con criterios responsive; no se exige una imagen por ruta para comenzar.
