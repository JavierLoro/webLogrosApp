JavaScript moderno

El lenguaje que hace funcionar todo: navegador, servidor y herramientas.

¿Por qué existe esto?

Antes de JavaScript, las páginas web eran documentos estáticos. Para cualquier interacción (validar un formulario, mostrar un mensaje de error) había que recargar la página entera y esperar una respuesta del servidor. JavaScript nació en 1995 para ejecutar lógica dentro del navegador, sin viajes de red. Con el tiempo se expandió al servidor (Node.js) y hoy es el único lenguaje que corre en todos los eslabones de una aplicación web: interfaz, backend y herramientas de build.

Variables: const y let

En JavaScript moderno (ES6+) ya no se usa var. Hay dos palabras clave:

Palabra clave¿Se puede reasignar?Cuándo usarla
constNoCasi siempre (valor que no cambia)
letSíContadores, acumuladores, estado que muta
 
const nombre = "valor"   // no cambia
let contador = 0         // puede cambiar

Aviso

Preferir siempre const. Solo bajar a let cuando realmente necesites reasignar. Esto hace el código más predecible: si ves const, sabes que el valor no cambiará más abajo.

Arrow functions (funciones flecha)

Son una sintaxis más compacta para definir funciones. Además, capturan el contexto this del lugar donde se definen, lo que evita muchos errores clásicos de JavaScript.

// Una línea — return implícito (no hacen falta llaves ni return)
const sumar = (a, b) => a + b

// Varias líneas — sí necesitan llaves y return
const saludar = (nombre) => {
  const mensaje = `Hola ${nombre}`
  return mensaje
}

Template literals

Permiten incrustar expresiones dentro de un string sin concatenar con +. Se delimitan con backticks (`) en lugar de comillas.

const nombre = "Javier"
const mensaje = `Hola ${nombre}`   // backticks ` y ${variable}
// resultado: "Hola Javier"

Objetos y arrays

Un objeto agrupa propiedades relacionadas bajo una misma variable. Un array es una lista ordenada de valores.

// Objeto — clave: valor
const usuario = {
  nombre: "Javier",
  puntos: 150
}
console.log(usuario.nombre)   // acceder a una propiedad → "Javier"

// Array — lista indexada desde 0
const logros = ["Primer login", "Primera tarea"]
console.log(logros[0])        // → "Primer login"
console.log(logros.length)    // → 2

async / await — código que espera

Las operaciones lentas (consultar una base de datos, llamar a una API) no son instantáneas. JavaScript es no bloqueante: en lugar de congelar el programa mientras espera, gestiona estas operaciones de forma asíncrona. async/await es la sintaxis moderna para escribir ese código como si fuera secuencial.

// Cuando el código tiene que esperar (BD, APIs, etc.)
const obtenerUsuario = async (id) => {
  const usuario = await consultarBaseDeDatos(id)
  // esta línea NO se ejecuta hasta que la anterior termine
  return usuario
}

Aviso

await solo puede usarse dentro de una función marcada con async. Si lo olvidas, obtendrás un error de sintaxis.

Módulos — compartir código entre archivos

Los módulos permiten dividir el código en archivos y reutilizarlo. En Node.js con "type": "commonjs" (el sistema clásico) se usa module.exports y require. En TypeScript y ESM moderno se usa export e import (lo verás en la página de TypeScript).

// usuarios.js — exportar una función
module.exports = { obtenerUsuario }

// server.js — importar esa función
const { obtenerUsuario } = require("./usuarios")

En webLogrosApp

El backend usa estos conceptos desde el primer archivo. En apps/backend/src/server.ts, la constante PORT es un ejemplo de tipado (lo verás en TypeScript), y el callback de app.listen es una arrow function:

const PORT: number = 3001

app.listen(PORT, () => {
  console.log(`Servidor escuchando en http://localhost:${PORT}`)
})

El template literal `Servidor escuchando en http://localhost:${PORT}` construye el mensaje de inicio con la variable PORT, exactamente como el ejemplo de la sección anterior.
