El proceso que has seguido, de principio a fin

Una guía de estudio de webLogrosApp: cada concepto explicado desde el problema que resuelve (first principles) y anclado al código real que escribiste.

Cómo usar este sitio

No es documentación de referencia: es un recorrido. Cada página empieza por ¿por qué existe esto? — el problema concreto que apareció — y termina mostrándote cómo lo aplicaste en webLogrosApp, con rutas de archivo reales (como apps/backend/src/server.ts) y fragmentos de tu propio código. Si estás perdido, léelas en orden: reconstruyen la intuición desde cero.

📍 Dónde estás ahora

Fases 1–5 completadas (base, web pública, auth JWT, base de datos, despliegue en Docker + Proxmox). Ahora mismo en Phase 5.5 — Hardening: arreglando las URLs del frontend (de localhost:3001 hardcodeado a rutas relativas /api/*). El detalle completo, en la página Visión y roadmap.
