# Prompts de exploración de superficies

Generación realizada con la herramienta integrada de imágenes. Bloque común: superficies vacías y de bajo contraste para Lockerboard, sin texto, logotipo, interfaz ni iconos; paleta carbón, grafito, claro, coral controlado y naranja mínimo.

## A — Taquilla metálica

Lámina cuadrada 2×2 con metal perforado y señal coral para logro; metal pintado con carriles prensados para ranking; puerta de taquilla mate con junta y remaches para contenedor; metal técnico con ventilación y muesca naranja para datos. Fotografía macro ortogonal, sin óxido, suciedad industrial ni cromo.

## B — Archivo deportivo

Lámina cuadrada 2×2 con cartulina oscura, pestaña coral y cinta para logro; capas de papel y tejido con bandas para ranking; cartón mate con clip y esquinas fotográficas para contenedor; tejido técnico con costura, bolsillo vacío y marcas para historial/datos. Sin fotografías, escritura, scrapbook o estética nostálgica.

## C — Marcador editorial

Lámina cuadrada 2×2 con campo segmentado y banda coral para logro; carriles y halftone por nivel para ranking; retícula técnica y plano diagonal para contenedor; trazas segmentadas, pulsos y scan lines para datos. Gráfica plana, sin dashboard, números digitales, HUD, neón o estética gamer.

## C refinada — ligera y sencilla

Lámina 3×2 con seis superficies planas: logro con una esquina coral y tres puntos; primer puesto con una línea coral fina; segundo/tercer puesto con línea clara y halftone tenue; contenedor con retícula casi invisible; datos con un único pulso segmentado y muesca naranja; bloqueado con una línea interrumpida. Cada superficie conserva 80–90% de espacio limpio, detalles solo 2–6% más claros que el fondo y coral por debajo del 8%. Sin textura fotográfica, 3D, ruido intenso, UI ni texto.
