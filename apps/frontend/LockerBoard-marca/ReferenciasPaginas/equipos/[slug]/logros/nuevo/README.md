# Crear / editar logro

## Ampliación acordada: proponer un logro (pendiente de implementación)

Esta ruta también permitirá a cualquier miembro proponer un logro para el equipo actual. Para PLAYER, mostrar nombre, descripción, criterios, imagen y «Enviar propuesta». La obtención solo se podrá solicitar desde el detalle después de aprobarse e incorporarse al catálogo. Indicar que queda pendiente de revisión; no se concede el logro ni se publica directamente. TEAM_ADMIN conserva la creación directa.


Ruta: `/equipos/[slug]/logros/nuevo`.

Estado: **Referencia disponible; cobertura parcial**.

Referencia: [Abrir imagen](../../../../_compartidas/detalle-y-formulario-logro-desktop-v1.png).

Panel derecho de la lámina compartida: creación administrativa. La edición dispone ahora de imagen propia; ver referencias vigentes.

Pendiente transversal: versión móvil y estados de carga, vacío, error y acceso restringido cuando correspondan. La referencia visual no acredita que la funcionalidad esté implementada.

## Referencias vigentes verificadas

- [Proponer logro — jugador](nuevo-logro-desktop-v1.png): formulario disponible y válido para proponer; no necesita una casilla de obtención. Primero aprobación e incorporación al catálogo, después solicitud desde el detalle.
- [Editar logro](editar-logro-desktop-v1.png): edición con datos, guardar y cancelar disponible.
- Creación administrativa: se conserva el panel derecho de la lámina compartida.

No hace falta aportar otra imagen de propuesta desde cero ni renombrar el archivo existente. La URL específica de edición sigue pendiente de definir.
